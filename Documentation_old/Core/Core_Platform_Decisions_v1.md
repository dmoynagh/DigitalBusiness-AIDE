
# Core Platform / Working Surface — Decisions

> **Version 1** (2026-09-02). Records the initial generic platform-fact decisions.

## D1 — Facts, mechanisms and deployed state are separate

A surface's capabilities, its supported deployment mechanisms and a particular environment's
actually deployed/current AIDE state answer different questions and remain separate.

## D2 — Evidence controls confirmation

Current product documentation may identify candidates for testing, but only evidence accepted by
the owning process becomes a confirmed AIDE platform fact.

## D3 — No broad schema yet

The initial model is an extensible factual record, not a frozen platform taxonomy.
