## K1 — OpenAI surface/deployment-route empirical baseline

**Status:** Current point-in-time evidence; re-test before treating as permanent product behaviour.

- Codex CLI/local plugin validation and explicit/implicit Skill triggering were proven, including a
  negative-trigger case. Updates were session/cache bound in the test.
- ChatGPT Cloud Work personal standalone Skill triggering was proven in Web Work and desktop Cloud
  Work. The same remote Skill updated in place and was resolved by existing/new Work conversations.
- The tested local Codex plugin did not prove ordinary Chat runtime execution and did not appear in
  ChatGPT web. The personal Cloud Work Skill was not available in ordinary Chat or Codex's local
  Skill picker.
- The proven practical split at that date was Codex CLI/local plugin; ChatGPT Cloud Work/personal
  standalone Skill; ordinary Chat/project-context Bundle fallback.
- UI/metadata presence was weaker evidence than a successful runtime probe. Representation,
  distribution channel and runtime surface must remain separate facts.

Newer possible OpenAI routes are candidates for controlled testing, not confirmed facts.

**Related:** Capabilities Capability Build; AI Deployment.
